# Введение
Учебный проект для мониторинга доступности API, анализа логов и работы с трафиком

## Этап 6. SSH и SCP
### 1. Генерация SSH-ключей
Для создания пары ключей используется команда: 
```bash
ssh-keygen -t ed25519 -C "<комментарий>"
```
В результате создаются два файла:
- id_ed25519 - приватный ключ
- id_ed25519.pub - публичный ключ
Приватный ключ никогда не покидает локальную машину, а публичный ключ используется для проверки подлинности на стороне сервера.

### 2. Копирование публичного ключа
Копирование публичного ключа на сервер позволяет проходить аутентификацию автоматически без постоянного ввода пароля пользователя.

Для добавления публичного ключа используется команда: 
```bash
ssh-copy-id -i ~/.ssh/id_ed25519.pub <пользователь>@<сервер>
```

После этого можно подключаться к серверу по SSH командой: 
```bash
ssh <пользователь>@<сервер>
```

### 3. Передача проекта через scp
Код упаковывается в архив для ускорения транспортировки и отправляется по защищенному каналу.

Данной командой проект архивируется
```bash
tar -czf <проект>.tar.gz <проект>
```

Этой командой архив с проектом передается на сервер 
```bash
scp <проект>.tar.gz <пользователь>@<сервер>:~/
```

Данной командой архив распаковывается на сервере и удаляет файл самого архива за ненадобностью
```bash
ssh <пользователь>@<сервер> "tar -xzf ~/<проект>.tar.gz && rm ~/<проект>.tar.gz"
```
